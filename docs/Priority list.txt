Priority 1: Must-have (the minimum winning demo)
#	Feature	How to know it’s done
1	Mock data generator (moving dot, WCS, dates)	FITS files exist in data/mock/
2	Cutout + display of one image	One PNG shows in the browser
3	RA/Dec input form	Typing coordinates changes the image
4	Animation: play/pause + frame slider	A dot visibly moves across frames

6	All 5 test targets work	Preset buttons for each target
